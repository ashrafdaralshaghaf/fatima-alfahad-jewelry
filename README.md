# Fatima Alfahad Jewelry — المتجر الكامل

متجر إلكتروني متكامل: واجهة المتجر (`index.html` كما صمّمتها فاطمة، بدون تغيير في التصميم) + **Node.js/Express** + **PostgreSQL** + لوحة إدارة **React** على `/admin`.

```
index.html, a/        واجهة المتجر (التصميم الأصلي) — تُخدَّم على /
server/               الـ Backend (Express + PostgreSQL) — الـ API على /api
admin/                لوحة الإدارة (React + Vite) — تُخدَّم على /admin
```

## التشغيل المحلي (Windows / Mac / Linux)

المتطلبات: Node.js 20+ فقط (PostgreSQL مضمّن للتطوير، أو استعملي Docker/أي PostgreSQL).

```bash
npm run setup          # تثبيت الحزم وبناء لوحة الإدارة
npm run dev:db         # (نافذة 1) قاعدة PostgreSQL محلية للتطوير — اتركيها تعمل
cp server/.env.example server/.env     # ثم عدّلي القيم (APP_SECRET, ADMIN_EMAIL ...)
npm run seed           # (نافذة 2) إنشاء الجداول + تحميل المنتجات الحالية
ADMIN_EMAIL=you@example.com npm run create-admin   # ينشئ حساب المدير ويطبع كلمة مرور قوية مرة واحدة
npm run dev            # تشغيل الخادم → http://localhost:3000  (اللوحة: /admin)
npm test               # اختبارات التكامل (16 اختبار: auth, orders, admin, security)
```

> لتطوير لوحة الإدارة مع إعادة تحميل فوري: `npm run dev:admin` (المنفذ 5173، يمرّر `/api` للخادم).

## ماذا يعمل الآن
**المتجر:** المنتجات والمجموعات والفئات والأسعار وأسعار الصرف تأتي من قاعدة البيانات · التسجيل وتسجيل الدخول واستعادة كلمة المرور · صفحة "حسابي" (الطلبات، البيانات، تغيير كلمة المرور) · المفضلة تتزامن مع الحساب · الطلبات تُحفظ ويُعاد حساب السعر على الخادم · حجز المواعيد · طلبات التصميم الخاص مع رفع الصور · النشرة البريدية · إيميل تأكيد الطلب.

**لوحة الإدارة `/admin`:** نظرة عامة ومبيعات 30 يوماً · المنتجات (إضافة/تعديل/إخفاء/حذف، صور متعددة بترتيب، مخزون، سعر ألماس مختبري/طبيعي، عربي/إنجليزي) · الفئات (المقاسات والنقش) · المجموعات · الطلبات (الحالة، الدفع، ملاحظات، سجل زمني، إيميل للعميل، إرجاع المخزون عند الإلغاء) · العملاء (تعطيل الحساب) · المواعيد · طلبات التصميم الخاص (مع الصور الخاصة) · النشرة (تصدير CSV) · أسعار الصرف · تغيير كلمة المرور · سجل نشاط كامل.

## الأمان المطبَّق
- كلمات المرور: **scrypt** مع salt عشوائي · قفل الحساب بعد 5 محاولات فاشلة · رسائل خطأ موحّدة (لا كشف لوجود الحساب) · ردّ متساوٍ في الزمن.
- الجلسات: رمز عشوائي في كوكي `HttpOnly + SameSite=Lax (+Secure/__Host- في الإنتاج)`، يُخزَّن **مُجزَّأً (SHA-256)** في القاعدة ويمكن إبطاله؛ جلسة المدير 12 ساعة؛ تغيير/استعادة كلمة المرور يُنهي كل الجلسات.
- **CSRF:** ترويسة إلزامية + فحص `Origin`/`Sec-Fetch-Site` + SameSite.
- **CSP صارم** بدون `unsafe-inline` للسكربتات (بصمة SHA-256 للسكربت الداخلي)، وHSTS، وnosniff، وframe-ancestors none، وPermissions-Policy.
- تحقق كامل من المدخلات (zod) · استعلامات SQL مُعاملة (parameterized) فقط · تهريب HTML في الإيميلات والواجهة · حماية CSV من حقن الصيغ.
- **الأسعار تُحسب على الخادم** فقط (لا يُوثق بأي سعر من المتصفح) · التحقق من المقاس/الألماس/النقش/المخزون داخل معاملة قاعدة بيانات.
- الصور: تُفكّ وتُتحقق بـ sharp (JPEG/PNG/WebP فقط، لا SVG)، وتُعاد ترميزاً إلى WebP (يزيل EXIF)، بأسماء عشوائية؛ صور العملاء (التصميم الخاص) **خاصة** ولا يراها إلا المدير.
- تحديد معدّل الطلبات (عام، دخول، طلبات، نماذج) · رؤوس بدون `X-Powered-By` · سجل تدقيق لكل تعديل إداري.

## النشر (Production)
1. PostgreSQL مُدار (Neon / Supabase / Railway / RDS) ← ضعي `DATABASE_URL` و`DATABASE_SSL=true`.
2. على الخادم: `NODE_ENV=production`, `PUBLIC_URL=https://دومينكم`, `APP_SECRET` (32+ حرفاً عشوائياً), `TRUST_PROXY=1` خلف Nginx/منصة، وإعدادات `SMTP_*` و`ORDER_NOTIFY_EMAIL`.
3. `npm run setup && npm run migrate && ADMIN_EMAIL=... npm run create-admin && npm start` — **يجب** تشغيله خلف HTTPS.
4. خذي نسخة احتياطية دورية من PostgreSQL ومن مجلد `server/uploads` (وهو مجلد `server/private` للصور الخاصة).

## ما لم يُنفَّذ بعد (يحتاج قراراً/بيانات منكم)
- **بوابة الدفع (KNET / البطاقات):** الطلبات تُنشأ بحالة `pending / unpaid` ويؤكد المدير الدفع يدوياً من اللوحة. للدفع الإلكتروني الفعلي نحتاج حساب تاجر (مثل MyFatoorah أو Tap أو KNET المباشر) ثم نربطه — الكود مهيّأ لذلك في `server/src/services/orders.js`. (نص "معاينة تصميم، لا تتم معالجة أي دفع" في صفحة الدفع ما زال كما هو.)
- المصادقة الثنائية (2FA) للمدير — يُنصح بها قبل الإطلاق.
- تحديد المعدّل مخزَّن في ذاكرة الخادم (يكفي لخادم واحد؛ مع عدة خوادم يلزم Redis).
- نصوص الشروط تحتوي حقولاً فارغة: `[Official Customer Service Email]` و`[Official Website URL]` و`[Official Instagram Account]` — يجب تعبئتها في `index.html`.
